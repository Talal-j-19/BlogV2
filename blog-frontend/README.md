# Blog Generator Frontend

A modern React-based frontend for the AI Blog Generator API.

## Features

- Generate blog posts with AI
- Copy or download generated content
- Responsive design
- Beautiful markdown rendering
- Blue, purple, and violet color scheme

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Make sure your backend API is running at `http://localhost:8000`

## Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
